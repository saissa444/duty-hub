# 班表111

把「勤務表」與「在班表」合在一起：匯入勤務基準表排出每日勤務分配表，排好之後直接看在班關係，並依實際班別計算加班時數。

- 網址：https://saissa444.github.io/duty-hub/
- 可加入 iPhone 主畫面，第一次開啟後可離線使用
- 資料只存在各裝置的瀏覽器；換裝置請用「設定 → 備份與還原」
- 舊的「勤務表」「在班表」資料可在「設定 → 從舊 App 搬資料」帶入（只讀取，不修改舊資料）
- 本網站不含人員姓名，姓名請在「設定」填寫

## 加班計算方式

依實際班別（含班別修改）計算：白天班上班滿 9 小時之後算加班；18 點以後起班跨夜者，隔日 06–09 算加班，09 點後繼續上班超過 9 小時的部分也算。加班時段內登錄的差假、兼課時段，以及在勤務分配表上把這個人的格子清空的時段，都會扣掉（例：09–21 請 12–19，只算 19–21 共 2 小時）。
